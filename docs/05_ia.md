# 05 — Chat e integración de IA

## Idea central

El chat produce siempre una **intención**: un JSON que la app convierte en tarjeta de
confirmación. Nivel 1 (MVP) la produce un intérprete por reglas en el teléfono; Nivel 2
(futuro) la produce un modelo de IA en una Cloud Function. La app no cambia entre niveles.

```
Chat en la app ──Nivel 1 (reglas, offline)──────────────┐
      │                                                 ▼
      └──Nivel 2──► Cloud Function `asistente` ──► intención ──► Tarjeta ──► [Guardar] ──► Firestore
                     ├ Genkit (una interfaz)
                     ├ Secret Manager (API key)
                     └ Herramientas de solo lectura
                           │
                           ▼
                 Claude · Gemini · GPT · compatibles/locales (por configuración)
```

## Formato de intención

```json
{
  "accion": "proponerMovimiento",
  "tipo": "gasto",
  "monto": 85000,
  "categoria": "alimentacion",
  "fecha": "2026-11-18",
  "nota": "mercado",
  "deudaId": null,
  "confianza": 0.92
}
```

Acciones válidas:
| accion | Campos | Resultado en la app |
| --- | --- | --- |
| `proponerMovimiento` | tipo, monto, categoria \| deudaId, fecha, nota | Tarjeta [Guardar] [Cambiar] |
| `consultarEstado` | — | "Llevas $X de $Y. Te quedan $Z por día." |
| `consultarCategoria` | categoria | Total de la categoría en el período |
| `consultarDeuda` | deudaId | Saldo y próxima fecha de pago |
| `pedirCorreccion` | movimientoId, cambios, motivo | Tarjeta que crea una solicitud al admin |
| `noEntendido` | textoOriginal | Abre el formulario prellenado con lo que se pudo extraer |

## Nivel 1 — intérprete por reglas (slice 8)

- Montos: "85 mil", "85.000", "85000", "1,2 millones", "1.2 M", "un millón".
- Tipo: "gasté/pagué/compré" → gasto; "me pagaron/recibí/me entró" → ingreso; "pagué la cuota de X" → pagoCuota (X = nombre de deuda, coincidencia aproximada).
- Categoría por diccionario (archivo `app/lib/features/chat/domain/diccionario.dart`): mercado, almuerzo, restaurante → alimentación; uber, gasolina, bus → transporte; luz, agua, internet, celular → servicios; arriendo, administración → vivienda; droguería, médico → salud; colegio, curso → educación; cine, salida, ropa → ocio; resto → otros.
- Fechas: "hoy" (defecto), "ayer"; fuera del período vigente → aviso.
- Preguntas fijas: "¿cómo voy?", "¿cuánto llevo en X?", "¿cuánto debo de X?", "¿cuándo pago X?", "¿cuánto me queda?".
- Tests: tabla de ≥ 60 frases reales de la familia con su intención esperada.

## Nivel 2 — IA (Etapa 4, NO implementar en el MVP)

- Cloud Function `asistente` con **Genkit**: una sola interfaz para Gemini, Claude, GPT y APIs compatibles con OpenAI o modelos locales. El proveedor y el modelo salen de `hogares/{h}.ia`.
- API key en **Secret Manager** (`defineSecret`). Nunca en la app.
- "Trae tu llave": el admin pega la key del hogar → Function la guarda cifrada en Secret Manager → nunca se puede leer de vuelta desde la app.
- Herramientas (function calling) que la IA puede usar — todas de **solo lectura** o que devuelven intenciones:
  `leerResumenPeriodo`, `leerMovimientosRecientes(n)`, `leerDeudas`, `leerPresupuesto`, `proponerMovimiento`, `pedirCorreccion`.
- La IA **nunca escribe** en Firestore. El usuario confirma cada tarjeta.
- Permisos: solo datos que el usuario ya puede ver; datos de todos solo si es admin.
- Privacidad: enviar totales y movimientos recientes; sin correos; nombres como "Miembro A". El admin activa la IA para el hogar y lo informa a la familia.
- Costos: `ia.limiteMensual` de mensajes por hogar; registro en `usoIA`.
- Usos en orden de valor: frases libres en el chat · lectura de recibos (foto → monto y comercio) · consejos al cierre de período · preguntas abiertas.

## Puertas que se dejan listas en el MVP

1. Formato de intención (usado ya por el Nivel 1).
2. `chats/{uid}/mensajes` guardando texto, rol, intención y estado.
3. `resumenes/{uid}_{periodoId}` al cierre de cada período.
4. Campo `hogares/{h}.ia` con `activa: false`.
5. Function `asistente` desplegada, apagada, que responde "próximamente".
